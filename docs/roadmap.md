# 後續開發順序

本檔是後續功能規劃，不表示這些功能已完成。

0.3 已完成住宅陽台與細節重建、較大尺度頂加、獨立頂加比例、程序材質調整、透視相機與自然環境照明，以及 0.1／0.2 場景升級。0.4 已加入獨立道路立體、人行道、電桿、電信箱、架空線、格柵、人孔蓋與三種街道預設。0.5 已加入曲線道路：區域網格內畫的游離邊（或選配的外部 Curve 物件）驅動的道路斷面掃出、沿建築線排列並可選擇彎折的街屋、屬性驅動的道路標線，以及沿曲線配置的電桿／電信箱／排水設施／架空線；未指定曲線時仍走原本的正交網格分支。0.6 已加入路口：多條道路邊在共用頂點（度數 ≥ 3）處自動偵測為路口，路面用 `Mesh Boolean UNION` 聯集並補上圓角，人行道在路口附近抑制成平面瀝青，`tc_junction_dist` 從「距曲線端點」換成「距最近路口」的真實距離（介面不變），架空線在路口附近中斷；轉角基地排除沿用 0.5 的 Group ID 規則。轉角雙立面資產（兩側開店的轉角建築模型）**尚未實作**，屬於資產建模工作，留待後續。詳見 [`docs/PLAN.md`](PLAN.md)。以下仍為未完成規劃。

## 下一步：提高近景寫實度

- 專用轉角模組：兩側開店、轉角騎樓和圓角磁磚立面，讓道路交叉處不再露出普通側牆。
- 將招牌、冷氣、鐵窗、植栽、屋頂獨立成可加權替換的資產集；減少固定組合的重複感。
- 前後進深及面寬不規則分割；區分公寓、透天、老街、較新集合住宅的尺度規則。
- 引入實拍掃描 PBR 材質、局部破損幾何與更多不同屋頂平面，改善近景和重複資產的限制。
- 側邊末戶專用立面；空置基地轉為機車停車場或小型綠地。

## 下一階段：轉角資產與街廓收斂（docs/PLAN.md §5 0.6.0／0.7.0）

- 0.6 尚未完成的部分：**轉角雙立面模組**——兩側開店、轉角騎樓和圓角磁磚立面，取代現有 42 組單面臨街資產在路口附近露出的普通側牆；純資產建模工作，不需要新的節點邏輯。
- 0.7：收斂成單一管線——正交網格改寫為內建的等距直線曲線產生器，移除 0.5／0.6 的雙分支；由道路網切分街廓多邊形，街廓內再切分建築基地；殘餘空地轉停車場／綠地；曲率過大時的基地略過規則與 UI 警示。
- 用 attribute / vertex group 控制區域樓高、商業比例、年代及空置密度。
- 坡地處理、地形標高取樣、騎樓高程連續性與建築底座。

## 資產規模與輸出

- LOD / 距離細節開關，將近景鐵窗與設備替換成遠景簡化版本。
- 廟宇、小吃攤、夜市、更多電桿樣式、交通號誌、路樹和街道家具。
- glTF / FBX 匯出配套與材質烘焙；保留街廓、基地和道路資料，供遊戲引擎使用。

- 擴充到其他 Blender LTS 版本，加入多版本 CI 與版本遷移測試。
