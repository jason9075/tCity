# 後續開發順序

本檔是後續功能規劃，不表示這些功能已完成。

0.3 已完成住宅陽台與細節重建、較大尺度頂加、獨立頂加比例、程序材質調整、透視相機與自然環境照明，以及 0.1／0.2 場景升級。0.4 已加入獨立道路立體、人行道、電桿、電信箱、架空線、格柵、人孔蓋與三種街道預設。0.5 已加入曲線道路：區域網格內畫的游離邊（或選配的外部 Curve 物件）驅動的道路斷面掃出、沿建築線排列並可選擇彎折的街屋、屬性驅動的道路標線，以及沿曲線配置的電桿／電信箱／排水設施／架空線；未指定曲線時仍走原本的正交網格分支。0.6 已加入路口：多條道路邊在共用頂點（度數 ≥ 3）處自動偵測為路口，路面用 `Mesh Boolean UNION` 聯集並補上圓角，人行道在路口附近抑制成平面瀝青，`tc_junction_dist` 從「距曲線端點」換成「距最近路口」的真實距離（介面不變），架空線在路口附近中斷。0.6.3 已補上轉角雙立面：近似直角路口的轉角基地改放簡化的轉角雙立面建築（兩片既有立面繞角落轉 90° 拼接、圓角磁磚牆角銜接），取代原本沿用 0.5 Group ID 規則留下的空地；銳角、鈍角路口與偵測不到真實路口的情況仍維持空地。詳見 [`docs/PLAN.md`](PLAN.md) 與 [`tcity/README.md`](../tcity/README.md) 的已知限制。以下仍為未完成規劃。

0.6.4 已新增獨立的新式住宅社區 GN 生成器：三種住宅類型、6–24 層組合、共用庭園、完整基地容納檢查與社區道路。尚未實作新舊住宅在同一演算法混排，或新式社區沿手繪道路配置，詳見 [新式社區說明](modern-communities.md)。

## 下一步：提高近景寫實度

- 轉角雙立面模組的已知限制：對稱十字路口的同一個角，可能被南北向與東西向街道各自判定為轉角而各放一棟，尚未做跨街道去重；也還沒有專門建模的轉角資產（現況是既有立面拼接），細節密度不如專用模型。
- 將招牌、冷氣、鐵窗、植栽、屋頂獨立成可加權替換的資產集；減少固定組合的重複感。
- 前後進深及面寬不規則分割；區分公寓、透天、老街、較新集合住宅的尺度規則。
- 引入實拍掃描 PBR 材質、局部破損幾何與更多不同屋頂平面，改善近景和重複資產的限制。
- 側邊末戶專用立面；增加停車格、植栽與街具的近景細節。

## 下一階段：街廓收斂（docs/PLAN.md §5 0.7.0）

- **已完成（0.7 開發版）**：正交網格改寫為內建、共用頂點的直線道路網；未提供道路時也走與手繪／外部曲線相同的路面、基地、設施與架空線管線，已移除 0.5／0.6 雙分支。手繪游離邊及外部 Curve 仍優先，UI 參數名稱不變。
- **已完成（0.7 開發版）**：道路專用切割體把殘餘地面分成獨立街廓並寫入 `tc_block_id`；未建築的有效沿街基地依 `Parking Mix` 轉成停車場或口袋綠地，並提供 `Open Spaces` 總開關。
- **已完成（0.7 開發版）**：以前後基地弦向量偵測急彎，依彎折／剛體模式套用不同安全門檻；超限基地自動略過，輸出 `tc_curvature_warning` 並在側欄顯示警示。
- **已完成（0.7 開發版）**：從殘餘街廓頂面直接篩出位於道路外緣距離帶的臨路邊界，沿該 frontage 生成 `Frontage × Depth` 顯式基地面；基地繼承 `tc_block_id`，建築與空地改由面中心生成，`Parcel Guides` 可顯示 `tc_layer = 7` 的檢查面。正常頂面輸出不再使用中心線兩側候選排；若 Blender EXACT 差集只留下側壁，會自動回退舊排以避免整區消失。中心線舊路徑也保留給轉角雙立面專用判定。
- **已完成（0.7 開發版）**：基地檢查面改用 8 × 8 細分網格，逐面依所屬街廓表面裁切，並把每個 cell 指派給最近的 parcel center，避免多面臨路候選重複占用；窄街廓、斜邊與區域邊緣會顯示小於 `Frontage × Depth` 的不規則輪廓，同時保留 `tc_parcel_id`／`tc_block_id`。建築與空地仍只使用通過完整容納檢查的基地。
- 開發版限制：內建正交路口的顯示網格暫時保留同高道路斷面重疊，避免 Blender 5.2 的非凸斷面 self-union 把抬高路緣壓平；街廓切割改用獨立凸形刀具，不受此限制。
- 將目前的細分近似輪廓收斂成精確梯形／任意多邊形地籍。
- 用 attribute / vertex group 控制區域樓高、商業比例、年代及空置密度。
- 坡地處理、地形標高取樣、騎樓高程連續性與建築底座。

## 資產規模與輸出

- LOD / 距離細節開關，將近景鐵窗與設備替換成遠景簡化版本。

- 擴充到其他 Blender LTS 版本，加入多版本 CI 與版本遷移測試。
