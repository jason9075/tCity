# 後續開發順序

本檔是後續功能規劃，不表示這些功能已完成。

0.3 已完成住宅陽台與細節重建、較大尺度頂加、獨立頂加比例、程序材質調整、透視相機與自然環境照明，以及 0.1／0.2 場景升級。0.4 已加入獨立道路立體、人行道、電桿、電信箱、架空線、格柵、人孔蓋與三種街道預設。以下仍為未完成規劃。

## 下一步：提高近景寫實度

- 專用轉角模組：兩側開店、轉角騎樓和圓角磁磚立面，讓道路交叉處不再露出普通側牆。
- 將招牌、冷氣、鐵窗、植栽、屋頂獨立成可加權替換的資產集；減少固定組合的重複感。
- 前後進深及面寬不規則分割；區分公寓、透天、老街、較新集合住宅的尺度規則。
- 引入實拍掃描 PBR 材質、局部破損幾何與更多不同屋頂平面，改善近景和重複資產的限制。
- 側邊末戶專用立面；空置基地轉為機車停車場或小型綠地。

## 下一階段：道路曲線與區域控制

- 輸入道路 Curve，處理路口與路寬；以道路切分街廓、街廓再切分建築基地。
- 讓每棟建築朝向最近街道，而非固定兩排；支援轉角與非正交配置。
- 將保守外接圓邊界檢查改為更貼合基地形狀的完整 footprint 包含判斷。
- 用 attribute / vertex group 控制區域樓高、商業比例、年代及空置密度。
- 坡地處理、地形標高取樣、騎樓高程連續性與建築底座。

## 資產規模與輸出

- LOD / 距離細節開關，將近景鐵窗與設備替換成遠景簡化版本。
- 廟宇、小吃攤、夜市、更多電桿樣式、交通號誌、路樹和街道家具。
- glTF / FBX 匯出配套與材質烘焙；保留街廓、基地和道路資料，供遊戲引擎使用。
- 使用者資產介面：定義樓層、標準 footprint、正面方向和細節插槽。
- 擴充到其他 Blender LTS 版本，加入多版本 CI 與版本遷移測試。
