# 0.4 台灣道路與沿街設施

調研與實作日期：2026-09-08。本版將「區域 → 建築」擴充成共享街廓座標的道路、步行平台、沿街設備與架空線。建築仍採 0.3 台北住宅資產。

## 已實作

- **道路面**：GN 建立封閉的區域立體，扣除前後排人行道平台，得到獨立瀝青路面與後巷；支援厚度。道路與平台使用 Boolean 裁切到真正區域，包括凹角、孔洞。
- **人行道與路緣**：沿街保留可調寬度，平台有抬高的頂面、鋪磚與實際垂直路緣。尚未製作路口斜坡與無障礙導盲磚。
- **道路細節**：兩個方向的雙黃線與斑馬線、磨耗遮罩、鑄鐵人孔蓋和排水溝蓋。標線仍為程序材質，並非獨立 UV 貼圖。
- **沿街設備**：電桿沿街廓兩側配置；電信箱與電桿錯開，箱體面向道路；人孔蓋在車道內，排水格柵在路緣外側。
- **架空線**：每段街廓的相鄰電桿之間有五條管狀線纜，依可調垂度下垂。端點與桿高連動；區域邊界的擴張管線搭配各導線方向 Raycast，排除會穿出邊界或穿越孔洞的整個跨段。
- **編輯流程**：建築、路面、步道、電桿、電信箱和架空線可分別顯示；不需要逐幀 Python handler。提供住宅街巷、地下化街道及道路檢視預設。

## 現階段邊界

道路仍是正交街廓，不能繪製任意道路曲線；沒有路口車流拓撲、號誌、轉彎半徑、坡地或交通模擬。架空線只沿同一段街廓配置，在路口和區域中斷處停止；沒有跨路接線、接戶線或真實配電網模擬。

所有電桿目前共用一套設備樣式。道路分層已為後續道路曲線、路口專用資產、電桿樣式庫與 LOD 留下可分開更換的實作位置。
