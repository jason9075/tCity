# TCity 0.7 開發版 · 單一道路管線

Blender 5.2 LTS extension。Preferences → Get Extensions → Install from Disk 安裝 ZIP 並啟用。

3D View → N → TCity，可新增街區、從選取的局部 XY 已填面 Mesh 生成、換種子、升級舊街區與建立實體網格複本。

預設 4–5 層台北老公寓，包含內縮陽台、鐵窗、冷氣、雨遮、小磁磚、店面入口與屋頂生活空間。

- **住宅頂樓加蓋比例 / Rooftop Addition Mix**：0–1，預設 0.85。設為 0 仍保留樓梯間、水塔。預設比例是美術設定，不是都市統計。
- **獨棟鐵皮屋比例 / Metal Shed Mix**：0–1，預設 0。六種單層浪板小工廠／倉庫不受住宅樓層控制，也不另外加住宅頂加。
- **Rooftops**：同時控制頂加與屋頂設備；獨棟鐵皮屋的主屋頂保留。
- **升級街區**：支援 0.1／0.2／0.3，保留區域與控制值。舊節點樹和資產保留，但自訂節點改動不合併。
- **建立實體網格複本**：保留來源，產生初始隱藏的網格。這不是材質貼圖烘焙。

Geometry Nodes 即時配置道路與建築；同一檔案多個區域共用原創資產。平面區域可含凹角及真正留空的孔洞，使用前套用縮放。建議 100–200 m 區域，新增區域最大 1,000 m；道路中心線總長上限 5,000 m。尚無坡地；近似直角路口的轉角基地會放上簡化的轉角雙立面建築（見 0.6.3），其他角度仍留空地。

0.7 開發版的內建道路會切開殘餘地面，每個連通街廓寫入 `tc_block_id`。`Open Spaces` 預設開啟，會把通過完整基地容納檢查但未抽中建築的沿街基地改成停車場（`tc_layer = 5`）或口袋綠地（`tc_layer = 6`）；`Parking Mix` 控制兩者比例。依街廓裁切的任意形狀地籍仍待完成。

一般沿街基地現在直接從殘餘街廓的臨路頂邊抽取 frontage，不再固定從道路中心線向兩側建立候選排。系統沿 frontage 生成 `Frontage × Depth` 的矩形基地面、向街廓內退入半個 `Depth`，並直接繼承 `tc_block_id`；建築與空地由基地面中心生成。開啟 `Parcel Guides` 可顯示 `tc_layer = 7` 的基地面。若 Blender 的複合路口布林結果沒有街廓頂面，會自動回退中心線排；轉角雙立面也仍使用專用中心線判定。基地尚未依不規則街廓邊界裁成梯形或任意形狀。

這是朝寫實方向開發的程序化原型，並非掃描資產或照片級資產庫，亦非 iCity 官方產品。程式與原創模型 GPL-3.0-or-later；招牌字型 SIL OFL（fonts/OFL.txt）；Poly Haven 照明 HDRI 為 CC0（environment/CREDITS.txt）。


0.4 新增實體瀝青道路、人行道、路緣、排水格柵、人孔蓋、黑黃警示帶電桿、電信箱與架空線。道路與平台以 Geometry Nodes 布林裁切到輸入區域，包含凹角和孔洞。

- Road Surface／Sidewalks：分別開關道路和鋪面平台；Ground 是兩者的總開關。
- Sidewalk Width／Curb Height／Road Thickness：控制寬度、高度和厚度。
- Utility Poles／Telecom Cabinets／Overhead Wires：電桿、交接箱與架空線的獨立開關。
- Pole Spacing 是最大跨距；Pole Height 與 Cable Sag 同時更新線路支點與垂度。
- Cabinet Density 控制電信箱出現機率；建築 Density 不影響沿街設施。
- Road Details 控制格柵與人孔蓋，須有可見道路；關閉電桿會同步隱藏架空線。
- 「住宅街巷／地下化／道路檢視」三個預設保留邊界、種子、樓層與頂加設定。

升級保留既有數值，但新增的人行道保留寬度會改變建築位置與數量。0.3 住宅資產可共用。電線只沿同一段街廓連接，在路口或區域中斷處停止；尚無跨路／接戶線、路口坡道或交通模擬。

## 0.5 · 曲線道路

在區域網格內（Tab 進入編輯模式）畫一段游離邊（不接觸區域邊界）當道路中心線，或在「道路曲線（選配）」欄位指定一個外部 Curve 物件。0.7 開發版已移除舊正交雙分支：完全不指定時會自動建立置中的正交道路網，並走相同的路面、基地、設施與架空線管線；手繪游離邊優先於內建網格，外部 Curve 優先於兩者。

- Smooth Streets：把游離邊平滑成 Catmull-Rom 曲線；折角路口（十字、T 字）請關閉此項維持直線段。
- Road Resolution：道路中心線取樣間距，數字越小道路越貼合但節點計算量越高。
- Bend Buildings to Curve（預設開）：讓沿曲線排列的街屋跟著曲率彎折，避免內側穿插、外側裂縫；會 Realize Instances，記憶體用量較高，緩彎路段可關閉節省資源。
- 相鄰基地弦向量超出安全轉角時，該基地會自動略過並在側欄顯示紅色警示。彎折模式容許的曲率半徑約為一個 `Depth`；關閉彎折時採更保守的 0.3 m 後緣誤差預算。
- 道路寬度、人行道、路緣、標線、電桿／電信箱／排水／架空線等控制與 0.4 共用同一組欄位，曲線與正交模式意義相同。
- 多條曲線交會處由「最近街道」判斷自動排除重疊基地。

## 0.6 · 路口

在區域網格內畫多條游離邊、讓它們共用同一個頂點（度數 ≥ 3），即可自動形成路口——不需要額外設定。

- 路面在路口處自動用 `Mesh Boolean UNION` 聯集成一片連續瀝青，並補上圓角填角，取代 0.5 各自獨立、交叉處會露出接縫的路面。
- 人行道與路緣在路口填角半徑內自動抑制，改為平面瀝青，避免路口中間出現不合理的路緣。
- `tc_junction_dist`（標線 shader 用來畫停止線／斑馬線的距離）從 0.5 的「距曲線端點」代理值，換成「距最近實際路口」的真實距離；shader 介面沒有變。
- 架空線跨距若會穿過路口填角範圍，該跨距直接省略（不會有電線橫越十字路口）。
- 只有畫在區域網格裡的游離邊會被偵測為路口；外部 Road Curves 物件目前不支援路口偵測（單一 Curve 資料塊沒有「共用頂點」的分支概念）。
- 沒有路口的單一街道（0.5 情境）不受影響：偵測不到路口時，路面不會多跑一次布林運算。
詳細設計與已知限制見 [`docs/PLAN.md`](../docs/PLAN.md)。

## 0.6.2 台灣農地

N 側欄 → TCity → 台灣農地。新增農地範例或由已填面 XY 區域生成。支援綠稻／金黃稻、蔬菜、果園、農路、灌溉明渠、紅磚及磁磚農舍、農用棚、自然樹林、混凝土電桿與架空線。所有配置由 Geometry Nodes 評估。可調外框與孔洞；內部目前為自動變形田格，不含手繪農路或坡地。舊農地可從側欄升級並保留控制值。

## 0.6.3 · 轉角雙立面建築

補上 0.6 留下的缺口：曲線道路的近似直角路口，原本被 0.5 規則排除的角地基地，現在會放上轉角建築，取代空地。

- **簡化資產**：不是專用轉角模型，而是兩片既有單面立面（`residential.py` 的 `_facade()`）繞角落轉 90° 拼接，中間用圓角磁磚牆角銜接。6 種樓層數 × 2 種鏡像方向 = 12 組資產（索引 42–53），接在既有 42 組後面（`assets.KIT_OBJECT_COUNT` 從 42 變成 54）。
- **範圍限制**：只處理近似直角的路口；銳角、鈍角或偵測不到實際路口（`tc_junction_dist` 來源）的情況維持 0.6 原本的空地行為。新增的 `Corner Buildings` 開關（預設開）可整體關閉回到空地。
- **已知限制**：對稱十字路口的同一個角，可能同時由兩條街道各自判定為轉角而各放一棟（例如南北向與東西向街道都認為某個角落是「自己的轉角」），角落出現兩棟相鄰轉角建築而非一棟；未做跨街道去重。丁字路口不受影響。
- 過程中同時修正兩個既有問題：`Bend Buildings to Curve` 關閉時，街屋朝向會塌回單一方向（`align` 節點吃到的是曲線域轉換後失效的 Tangent field，改讀已存的 `tc_site_normal`/`tc_site_tangent` 屬性）；以及路口分裂道路曲線時，`Resample Curve` 對兩段曲線各自強制取端點，導致同一個轉角基地重複出現兩次（加了 `Merge By Distance` 去重)。

詳細設計見 [`docs/PLAN.md`](../docs/PLAN.md) 與 [`docs/roadmap.md`](../docs/roadmap.md)。

## 0.6.4 · 台灣新式住宅社區

N → TCity → 新式住宅社區。新增範例或由純面 XY 區域生成單棟、雙棟及弧邊大陽台住宅，包含入口、庭院、樹池、屋頂設備與沿街設施。主要塔樓 6–24 層，一樓 4.5 m、上層 3.1 m，雙棟副棟可低兩層。Community Width / Depth 縮放整組 XY 尺寸；不拉伸樓高。

完整基地若碰到邊界或孔洞就整組略過；Density 控制基地密度，Buildings 關閉仍保留道路，Landscape 單獨控制庭園樹木。最多 400 個候選基地。此生成器採自動正交道路，尚未與舊街屋自動混排或沿手繪道路配置。原創幾何依建商完工照與社區街景研究，照片不包含於 ZIP；仍是程序化原型，非照片級資產庫。
